# Desktop-Publishing---II-TASK-5
Import a custom brush using Brush Tool (B) → Brush Settings → Import Brushes.
Create a new layer and use the custom brush to add stars, splashes, or decorative effects.
Set this brush layer's blending mode to Screen.
Import another texture or light effect on a new layer.
Change its blending mode to Overlay or Soft Light.
Select the main image or text layer and open Layer → Layer Style → Outer Glow.
Add creative text using the Horizontal Type Tool (T), such as “DREAM BEYOND”.
Adjust the font, size, color, and alignment.
Apply Drop Shadow or Gradient Overlay to the text using Layer Styles.
Rename and organize layers in the Layers panel: Background, Image, Filters, Brush Effects, Light Effects, and Text.
Save the editable project using File → Save As → PSD.
Export the final artwork using File → Export → Export As.
Select PNG or JPG, confirm the dimensions are 1200 × 800 px, and click Export.
